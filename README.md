# War Zone Evacuation

A web-based emergency evacuation management system designed to assist civilians during war or disaster situations by providing safe route guidance, emergency support, and real-time coordination.

## 🚀 Project Overview

War Zone Evacuation is a project aimed at improving civilian safety during emergency situations. The application helps users:

* Find the safest evacuation routes
* Access emergency shelters and resources
* Receive alerts and updates during critical situations
* Coordinate rescue and evacuation operations efficiently

This project focuses on creating a reliable and user-friendly platform that can support emergency response efforts.

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/chs018/War-zone-evacuation-.git
```

### 2️⃣ Navigate to the project folder

```bash
cd War-zone-evacuation-
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start the development server

```bash
npm start
```
